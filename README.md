# ChairLight: диагностика штатного USB

Это **диагностическая**, а не управляющая программа для Windows 11. Не установлено, что USB подсветки URZUS Energy UR-7351111 передаёт данные или что его RF-пульт использует какой-либо конкретный протокол. Программа сравнивает устройства Plug and Play до и после подключения кресла и показывает новые идентификаторы. Новое устройство может не иметь отношения к креслу; отсутствие устройства не доказывает, что USB предназначен только для питания.

## Сборка и запуск

В GitHub Actions откройте успешный запуск **Build Windows diagnostic**, скачайте артефакт `ChairLight-Diagnostic-Windows` и запустите `ChairLight-Diagnostic.exe`. Программа не подписана цифровой подписью; Windows может показать предупреждение SmartScreen.

1. Отключите кресло от USB.
2. Запустите программу, нажмите **Снимок без кресла** и дождитесь завершения.
3. Подключите кресло, подождите 10 секунд и нажмите **Сравнить**.
4. Скопируйте или сохраните результат. Проверьте его перед отправкой: идентификаторы могут содержать серийные номера. На время теста не подключайте другие устройства.

Программа использует Windows PowerShell и `Get-PnpDevice`, ничего не устанавливает на компьютер и не отправляет в сеть. Исходники: Python 3.12, стандартная библиотека; сборка: PyInstaller 6.11.1. Запуск тестов: `python -m unittest discover -s tests -v`.

## Что необходимо для управления

Фото пульта спереди и сзади, надписей на нём, USB-кабеля и блока управления, фото штекера и маркировки. Нужен и результат USB-диагностики. Информация о модели кресла и общая надпись RF Wireless не устанавливают ни частоту, ни модуляцию, ни команды. Если USB только питает подсветку, для управления штатным приёмником потребуется совместимый передатчик и подтверждённый протокол; обычный компьютер или приложение для телефона не гарантируют наличие такого радио. Не покупайте передатчик и не меняйте контроллер, пока совместимость не проверена. Не разбирайте включённую подсветку.
