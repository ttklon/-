# ChairLight: диагностика компьютера и USB

Это **диагностическая**, а не управляющая программа для Windows 11. Она помогает определить модель компьютера и доступные радиоадаптеры и сравнивает устройства Plug and Play до и после подключения кресла. Само наличие Wi-Fi/Bluetooth/RF-адаптера не доказывает, что он может воспроизвести сигнал штатного пульта. Новое устройство USB может не иметь отношения к креслу; отсутствие устройства не доказывает, что USB предназначен только для питания.

## Как пользоваться

1. В GitHub Actions откройте успешный запуск **Build Windows diagnostic**, скачайте артефакт `ChairLight-Diagnostic-Windows` и запустите `ChairLight-Diagnostic.exe`. Программа не подписана цифровой подписью; Windows может показать предупреждение SmartScreen.
2. Нажмите **Собрать сведения о компьютере**, дождитесь результата и проверьте его. Доступны кнопки **Копировать** и **Сохранить отчёт**.
3. Чтобы проверить USB кресла, сначала отключите его, нажмите **Снимок без кресла**, затем подключите USB, подождите 10 секунд и нажмите **Сравнить**. На время теста не подключайте другие устройства.

### Приватность

Программа работает локально и не отправляет отчёт в интернет. Сбор сведений о компьютере включает производителя и модель компьютера и материнской платы, модель CPU, версию Windows, названия и состояние подключённых сетевых, Bluetooth, USB, HID, портов и неопознанных устройств, производителя и версию драйвера и идентификаторы модели USB VID/PID или PCI VEN/DEV. Не экспортируются серийные номера ПК/платы, полный PnP Instance ID, IP или MAC-адреса, имена пользователей и сетей, пароли, документы и история браузера. Имена устройств могут содержать личные названия; MAC-адреса в распространённом формате в этих названиях маскируются, но автоматическая очистка не гарантирует отсутствие другой личной информации. **Проверьте отчёт перед отправкой.**

Старый режим сравнения USB по-прежнему выводит полные идентификаторы новых устройств, которые могут содержать серийные номера. В этом режиме тоже обязательно проверьте отчёт.

Программа использует Windows PowerShell, CIM и `Get-PnpDevice`, не устанавливает драйверы и не изменяет настройки. Исходники: Python 3.12, стандартная библиотека; сборка: PyInstaller 6.11.1. Запуск тестов: `python -m unittest discover -s tests -v`.
