# ChairLight — диагностика компьютера и USB

Программа для Windows 11 показывает сведения о компьютере, а также список устройств всех классов Plug and Play, в том числе отключённых, зарегистрированных Windows. Кроме того, она позволяет сравнить USB-устройства до и после подключения кресла. Это **диагностика**, не управление креслом. Наличие адаптера в отчёте не доказывает, что он может передавать радиосигналы штатного пульта.

## Скачивание и использование

В GitHub Actions откройте успешный запуск **Build Windows diagnostic**, скачайте артефакт `ChairLight-Diagnostic-Windows`, распакуйте ZIP и запустите `ChairLight-Diagnostic.exe`. EXE не подписан, поэтому Windows может показать предупреждение SmartScreen.

1. Нажмите **«Собрать сведения о компьютере»** и дождитесь окончания (может занять несколько минут).
2. Просмотрите отчёт, при необходимости удалите из него личные данные. Текст можно выделять мышью и редактировать; Ctrl+A выделяет всё.
3. Нажмите **«Копировать весь отчёт»** и вставьте его в сообщение через Ctrl+V. Копия останется в буфере после закрытия приложения. Если текста много или буфер обмена занят, нажмите **«Сохранить TXT»** и прикрепите созданный файл.
4. Чтобы проверить заявленные возможности USB-концентраторов, нажмите **«Проверить возможности USB-портов (без отключения)»**. Отчёт показывает дескрипторы концентраторов, а не реальную проверку подачи 5 В. Программа не умеет определять порт питания кресла, не переключает питание и не подтверждает возможность переключения в Windows.
5. При необходимости проверить USB кресла: отключите его, нажмите **«Снимок без кресла»**, подключите USB, подождите 10 секунд и нажмите **«Сравнить»**. На время теста не подключайте другие устройства.

## Состав и приватность

Отчёт о компьютере включает доступные Windows модели и производителя компьютера, платы, BIOS, CPU, RAM, GPU и дисков, версию Windows, все классы PnP-устройств (в том числе ранее подключённые/отключённые), их состояние, производителей, драйверы, а также модельные идентификаторы USB VID/PID, PCI VEN/DEV/SUBSYS или ACPI. Отсутствие устройства в списке не доказывает его физическое отсутствие. Если какую-то секцию получить не удалось, в конце отчёта есть предупреждение.

Программа работает локально и ничего не отправляет автоматически. При сборе отчёта она не запрашивает пароли, файлы, историю браузера, IP-адреса, MAC-адреса, имена сетей, серийные номера или полные PnP Instance ID. Имена устройств и некоторые свойства, предоставляемые Windows, могут содержать личную информацию; поэтому **проверьте отчёт до отправки**. Сравнение USB дополнительно может выводить полные идентификаторы новых устройств с серийными номерами — проверьте и их.

Программа использует Windows PowerShell, CIM, `Get-PnpDevice` и только читающий запрос Windows USB hub `IOCTL_USB_GET_NODE_INFORMATION`; не устанавливает драйверы, не отключает порты и не меняет настройки. Пути USB-концентраторов не включаются в отчёт, сохраняется только VID/PID. Исходники: Python 3.12 и стандартная библиотека; сборка: PyInstaller 6.11.1. Тесты: `python -m unittest discover -s tests -v`.
